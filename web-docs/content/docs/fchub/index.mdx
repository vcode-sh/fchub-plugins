**One calm place for every FCHub product on this site.**

FCHub is a small, optional plugin that adds a single place to your WordPress admin. From it you can see which FCHub products are installed, which ones are switched on, which have an update waiting, and which cannot run on this site yet — and then act on it without leaving the page.

That is the entire job. FCHub sells nothing, reports nothing about your site to anyone, and asks for no account.

<Callout type="info" title="Optional, always">
Nothing needs FCHub. Every product installs, updates, and uninstalls perfectly well on its own, exactly as it did before FCHub existed. FCHub is a nicer way to do those things, not a new requirement for doing them.
</Callout>

## What each product needs

They do not all agree, which is precisely why FCHub shows you compatibility instead of assuming it. Three of them want a newer WordPress and a newer PHP than the other three; all six want FluentCart.

| Product | WordPress | PHP | Also needs |
|---|---|---|---|
| Przelewy24 | 6.4 | 8.1 | FluentCart |
| Fakturownia | 6.4 | 8.1 | FluentCart |
| Portal Extender | 6.4 | 8.1 | FluentCart |
| Memberships | 6.7 | 8.3 | FluentCart |
| Wishlist | 6.7 | 8.3 | FluentCart |
| Multi-Currency | 6.7 | 8.3 | FluentCart |

If your site falls short of any of those, FCHub says so in a sentence — which product, which requirement, and what this site actually runs — rather than offering a button that would fail.

### What FCHub itself needs

| Requirement | Version |
|---|---|
| WordPress | 6.4 or newer |
| PHP | 8.1 or newer |
| FluentCart | Not required |

FCHub runs happily without FluentCart. It will still list the six products and still tell you, plainly, that they need FluentCart before they can do anything useful.

## What FCHub will and will not do

**It will** install a product, install and switch it on, switch an installed one on or off, and update one that has a newer release. It downloads only from official FCHub releases on GitHub, checks each download against its published checksum where one exists, and stops without changing anything if that check fails. WordPress does the actual installing, the same way it does for any plugin you upload yourself.

**It will not** delete a product, touch a product's settings or data, or change anything you did not ask it to. There is no Delete button, and that is deliberate: deleting a plugin is the WordPress Plugins screen's job, and it does it perfectly well.

## Removing FCHub

Deactivate it or delete it, and every product stays installed, stays switched on, and keeps its settings and data. Delete it and FCHub also clears the four values it stored for itself, leaving everything else exactly where it was.

This is not a promise we make from memory. An automated test installs a product through FCHub, deletes FCHub through the WordPress Plugins screen, and then checks that the product is still there and still running.

## The one that is not here

FCHub Stream was a video plugin for FluentCommunity. It is discontinued — retained as-is, with no support, no updates, and no place in the hub. It is not in the product list above and FCHub will not install it.
