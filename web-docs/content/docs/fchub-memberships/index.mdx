FCHub Memberships turns FluentCart purchases into useful, well-managed access.
Create an offer, choose what it unlocks, connect a product, and let the
membership lifecycle take care of itself.

Version 1.4.0 brings the whole experience together in a redesigned workspace.
The important work is easier to find, setup is guided, and problems arrive with
an explanation instead of a scavenger hunt. A surprisingly bold idea for a
WordPress admin screen.

## More capable, less dramatic

Membership access can come from purchases, subscriptions, manual grants, plan
relationships, and connected providers. FCHub Memberships keeps those sources
separate so one cancellation does not casually delete access that still belongs
to the member.

When a provider falls behind, the workspace keeps the issue visible and offers
a recovery path. When a webhook fails, you can see what happened, retry it, or
cancel work that should no longer run. When a payment catches up, recoverable
access can recover. It is the sort of boring reliability that becomes very
exciting five minutes after something goes wrong.

## Works with your stack

<Accordions type="single">
<Accordion title="FluentCart">

FluentCart powers purchases and subscriptions. Link products directly from a
membership plan or use FluentCart integration feeds for more advanced setups.
Paid orders grant access, renewals extend it, and cancellations or refunds
follow the access policy you choose.

</Accordion>
<Accordion title="FluentCRM">

Build automations around membership events, use membership data in messages,
segment contacts by access, and monitor whether CRM updates are healthy. If a
connection drifts, the Integrations workspace can preview and repair it.

</Accordion>
<Accordion title="FluentCommunity">

Grant access to supported spaces and courses alongside WordPress content.
Supported FluentCommunity Pro features appear only when the installed version
can provide them, rather than showing decorative controls that do nothing.

</Accordion>
<Accordion title="LearnDash">

LearnDash resources are available when a supported licensed installation is
active. Because “the class exists somewhere” is not the same as a certified
runtime, verify the provider status in **Memberships > Integrations** before
building a live course offer.

</Accordion>
</Accordions>
