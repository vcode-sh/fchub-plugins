This is the shortest route from deciding to sell a membership to a working
purchase and protected page. Allow about ten minutes, assuming nobody starts a
meeting halfway through.

## Build the first membership

<Steps>
<Step>

**Create the plan**

Go to **Memberships > Plans** and choose **Create Plan**.

In **Shape the offer**, give the plan a clear name and choose how long access
lasts:

- **Lifetime access** for a one-off purchase;
- **Fixed duration** for a set number of days;
- **Mirror subscription** when access should follow FluentCart billing;
- **Monthly billing anchor** when everyone renews against a calendar day.

Leave trials and advanced controls alone for the first test. They will still be
there later, waiting patiently and judging nobody.

</Step>
<Step>

**Choose what members receive**

Continue to **Choose content access**. Add one post or page and make it
available immediately.

You can add more items, community resources, categories, or a drip schedule
after the basic journey works. Choose **Review plan**, check the summary, and
create it.

</Step>
<Step>

**Link a FluentCart product**

Open the saved plan and select **Linked Products**. Choose **Link product**,
search for the product or variation, and confirm.

The connection grants this plan after a successful purchase. Advanced stores
can still configure Memberships integration feeds from FluentCart, but the
plan editor is the friendlier place to begin.

</Step>
<Step>

**Protect the content**

Content added to the plan is already protected. To create a separate rule, go
to **Memberships > Content** and choose **Protect content**.

The wizard asks for the content type, the exact resource, the plans that can
open it, and a final review. Choose a friendly restriction message or teaser so
visitors know what they are missing and what to do next.

</Step>
<Step>

**Run a test purchase**

Use a FluentCart test payment method:

1. place an order for the linked product;
2. complete the payment;
3. open **Memberships > Members** and find the customer;
4. confirm the plan appears as active;
5. visit the protected content as that member;
6. open the same page while logged out and confirm the restriction experience.

</Step>
<Step>

**Check the workspace**

Return to **Memberships > Dashboard**. The setup readiness should now recognise
an active plan, protected content, and a product connection. The purchase also
appears in recent activity.

Open the member profile to review access, dates, content progress, and any
connected community context.

</Step>
</Steps>

## Make it yours

<Accordions type="single">
<Accordion title="Release content over time">

Edit the plan and give later items a delay or fixed unlock date. Members can
see their progress and receive a message when something new becomes available.

Continue with [Drip Content](/docs/fchub-memberships/drip).

</Accordion>
<Accordion title="Offer a trial">

Add trial days to the plan. Access can convert after payment or end when the
trial finishes without one.

Continue with [Trial Periods](/docs/fchub-memberships/trials).

</Accordion>
<Accordion title="Design the emails">

Open **Memberships > Settings > Email Studio**. Choose whether each lifecycle
message uses the built-in email, a FluentCRM automation, or stays off. Built-in
emails can share a brand style while keeping their own content.

Continue with [Email Notifications](/docs/fchub-memberships/emails).

</Accordion>
<Accordion title="Connect another service">

Generate a read-only access key, create a membership API connection, or add an
independent webhook endpoint from **Memberships > Settings > Webhooks & API**.

Continue with [Webhooks & API](/docs/fchub-memberships/webhooks-api).

</Accordion>
</Accordions>
